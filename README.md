# Pub trivia for GNU Emacs

Pub trivia with multiple choice answers. Invoke the `pub-trivia`
command to get started. Then type 1, 2, 3, 4 to pick a choice. When
you go through all the questions, you will be presented with the
results.

+ Git repository: <https://github.com/protesilaos/pub-trivia>
